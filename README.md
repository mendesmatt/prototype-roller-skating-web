# Skating School — Student App

> Dynamic web app prototype for skating stores and urban sports communities, covering class schedules, private lessons and payments.

`HTML5` · `CSS3` · `JavaScript` · `Tailwind CSS (CDN)`

## 🇬🇧 English

**Segment:** Skating school & sports classes

Dynamic web app prototype for skating stores and urban sports communities, covering class schedules, private lessons and payments.

**Highlights**

- Class schedule with attendance confirmation
- Private one-on-one lesson booking
- Monthly fees, event tickets and receipts

**Tech:** HTML5, CSS3, vanilla JavaScript, Tailwind CSS via CDN.

**Run it:** Open `index.html` in any modern browser — no build step, no dependencies to install.

_This is a design prototype: data is mocked in the front-end and there is no back-end._
